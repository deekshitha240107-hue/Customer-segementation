Project Overview

This project performs customer segmentation using the K-Means Clustering algorithm in Python IDLE. The goal is to group customers based on their purchasing behavior and demographic characteristics, helping businesses understand different customer types and create targeted marketing strategies.

Objective
Analyze customer demographic and purchasing data.
Identify distinct customer groups using K-Means Clustering.
Visualize customer segments.
Generate business insights from customer behavior patterns.
Tools and Technologies
Python IDLE
Pandas
NumPy
Matplotlib
Scikit-learn
Dataset Features
Feature	Description
CustomerID	Unique customer ID
Age	Customer age
Gender	Customer gender
Income	Annual income
SpendingScore	Spending score assigned to the customer
PurchaseFrequency	Number of purchases made

Project Workflow
1. Data Collection
Import customer data from a CSV file.
2. Data Preprocessing
Handle missing values.
Remove duplicates.
Select relevant features for clustering.
Standardize numerical features.
3. Exploratory Data Analysis (EDA)
Analyze age distribution.
Analyze income distribution.
Analyze spending score distribution.
Identify patterns and trends in customer behavior.
4. Clustering
Use the Elbow Method to determine the optimal number of clusters.
Apply K-Means Clustering to group customers.
5. Visualization
Create histograms for feature distributions.
Plot the Elbow Curve.
Visualize customer segments using scatter plots.
6. Segment Analysis
Calculate average characteristics of each cluster.
Interpret customer groups and assign business labels.
